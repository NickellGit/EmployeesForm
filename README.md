# EmployeesForm: Система управления сотрудниками (WPF/MVVM)

Desktop-приложение для эффективного управления базой данных сотрудников организации. Проект демонстрирует принципы построения архитектуры на базе паттерна **MVVM**, работу с асинхронными процессами и безопасное взаимодействие с SQL-базами данных.

## Основные возможности
Приложение предоставляет полный набор функций для работы с картотекой персонала (CRUD):
- **Просмотр:** Вывод списка всех сотрудников из базы данных.
- **Добавление:** Создание новых записей сотрудников через интерфейс.
- **Редактирование:** Обновление данных существующих сотрудников.
- **Удаление:** Удаление записей из базы данных.
- **Асинхронность:** Все операции с базой данных выполняются в фоновых потоках, что исключает «зависание» UI.

## Технологический стек
- **Framework:** .NET, WPF.
- **Pattern:** MVVM (Model-View-ViewModel) для четкого разделения логики и представления.
- **Database:** SQL Server (ADO.NET).
- **Language:** C#.

## Архитектура проекта
Проект организован по принципам модульности, что упрощает масштабирование и поддержку:
- **/Models**: Описание сущности `Employee`.
- **/ViewModel**: Бизнес-логика приложения, команды (`RelayCommand`), связывание данных через `ObservableObject`.
- **/Services**: Слой доступа к данным (`DataBaseService`), изолированный от UI.
- **/View**: XAML-разметка интерфейса.

## Технические особенности реализации
- **Безопасность:** Взаимодействие с базой данных реализовано через параметры SQL-запросов, что гарантирует защиту от SQL-инъекций.
- **Responsiveness:** Использование `async/await` позволяет интерфейсу оставаться отзывчивым даже при выполнении тяжелых запросов к БД.
- **MVVM-инфраструктура:** Собственные реализации `ObservableObject` и `RelayCommand` обеспечивают чистоту ViewModels.

## Установка и запуск
1. Клонируйте репозиторий:
   `git clone https://github.com/NickellGit/EmployeesForm.git`
2. Откройте проект в Visual Studio (2022+).
3. Создайте базу данных, используя SQL-скрипт из файла `CreateDBWithTable.sql`.
4. В файле `App.config` (или `App.config` в корне) укажите корректную строку подключения (`connectionString`) к вашему SQL-серверу.
5. Запустите решение (Build & Run).
